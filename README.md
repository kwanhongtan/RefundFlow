# RefundFlow

An AI-powered customer refund workflow prototype developed for the **AI Systems & Agentic Workflow Automation Hackathon 2026**.

## Overview

RefundFlow is a prototype that streamlines customer refund processing through an AI-assisted workflow.

The workflow covers:

- Refund request intake
- Refund validation
- Order verification
- Review
- Approval
- Audit logging

## Technologies

- Python
- FastAPI
- HTML
- JavaScript
- Z.AI GLM
- REST API

## Running the Project

Start the backend with:

```bash
uvicorn customer_refund_backend:app --reload
```

Then open `customer_refund_app_realistic.html` in a web browser.

Additional API or environment configuration may be required depending on the setup.
